# Phân loại trái cây với CNN và YOLOv5

Dự án tập trung vào phân loại trái cây bằng các mô hình CNN và YOLOv5. Mã nguồn, dữ liệu, mô hình đã huấn luyện, ứng dụng demo và tài liệu được sắp xếp trong thư mục [`fruit_classfication/`](fruit_classfication/).

## Cấu trúc dự án

```text
fruit_classfication/
├── data/        Dataset (ví dụ: file .zip)
├── notebooks/   Notebook CNN, YOLOv5 và đánh giá
├── models/      Các mô hình đã huấn luyện
├── demo/        Ứng dụng minh họa dự đoán
└── report/      Báo cáo và slide
```

Xem [`fruit_classfication/README.md`](fruit_classfication/README.md) để biết chi tiết nội dung từng thư mục.
